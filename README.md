# 🧮 Calculadora Web

Uma calculadora simples desenvolvida com HTML, CSS e JavaScript puro.

## Funcionalidades

- Operações básicas: adição, subtração, multiplicação e divisão
- Visor para exibição dos valores
- Botão de limpar (C) para resetar os valores

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Como usar

1. Clone o repositório
2. Abra o arquivo 'calculadora.html' no navegador
3. Pronto!

## Estrutura
```
📁 projeto
├── calculadora.html
```
